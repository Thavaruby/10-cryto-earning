Free File Converter

Convert supported images and text files to PDF, or extract selectable PDF text into an editable Word document.

Convert files to PDF

Supported: JPG, JPEG, PNG, WEBP, TXT and CSV. Multiple images can be added to one PDF.

TXT and CSV are converted to readable text, not formatted spreadsheet tables.

Convert PDF to Word

Extract selectable text from a PDF into a DOCX document.

Page pictures preserve a visual reference. Extracted text is added separately; the original layout is not reconstructed as individually editable elements.

Supported formats

  • JPG/JPEG, PNG, WEBP → PDF
  • TXT, CSV → PDF
  • Selectable-text PDF → editable DOCX text
  • Optional PDF page images inside DOCX

Not supported: Word, Excel or PowerPoint → PDF; DOC/DOCX, XLS/XLSX or PPT/PPTX conversion; OCR of scanned PDFs; exact PDF-to-Word layout reconstruction. Original images, barcodes, signatures and icons are not automatically reconstructed as editable objects.

Files are processed in your browser and are not uploaded to a conversion API. JavaScript libraries load from public CDNs.
